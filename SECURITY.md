# Security Policy

## Reporting a Vulnerability

If you discover a security issue, please do not open a public GitHub issue first.

Please report it privately by contacting the repository maintainers through GitHub security advisories or direct maintainer contact, and include:

- A clear description of the issue
- Affected versions / commit hash
- Reproduction steps or proof of concept
- Suggested mitigation (if available)

## Response Expectations

- Initial acknowledgement: within 5 business days
- Status update after triage: within 10 business days
- Public disclosure: coordinated after a fix is available
